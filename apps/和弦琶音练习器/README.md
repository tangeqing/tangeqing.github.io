# Guitar Arpeggio Trainer｜吉他和弦琶音练习器

一个完全离线的吉他和弦琶音练习工具。无需安装、无需服务器、无需网络；直接双击 `index.html` 即可运行。

## 功能

- 28 种常用三、六、七、九、十一、十三及变化属和弦，自定义级数组合和弦，支持升降号显示。
- 标准、Drop D、全音降、半音降及六弦自定义 MIDI 调弦。
- 单和弦与可编辑和弦进行，含常用进行模板和自动移调。
- 固定范围、CAGED 近似把位和自动把位；范围 0–24 品。
- 基于六弦扫弦骨架的动态路径：每个和弦段必须覆盖 6→1 弦或 1→6 弦，只允许同弦或相邻弦移动，并限制连续同弦音数、同音重复和大幅换把。
- 上行、下行、往返、随机方向，转位、起始音和自定义级数音序。
- Canvas 动态 TAB：固定播放线、谱面左移、小节线、和弦名、符干/符尾、三连音标记和点击编辑。
- Canvas 指板：音名/级数显示，根音、当前、上一和下一音分层高亮。
- Web Audio 拨弦合成与节拍器，共用 AudioContext 提前调度时间轴。
- 30–300 BPM、Tap Tempo、多种拍号、细分、Swing、循环及音量/延音控制。
- 暂停、继续、停止、逐音/逐小节移动；后台自动暂停，避免恢复后错位。
- 深浅主题、专注模式、全屏、桌面/平板/手机响应式布局。
- 一键随机根音、和弦、把位、起始音与方向。
- localStorage 方案保存、另存、重命名、加载、删除；JSON 导入导出。

## 使用

1. 双击 `index.html`，使用 Chrome、Edge 或 Safari 最新版本打开。
2. 选择和弦、把位、方向及节奏，点击“生成练习”。
3. 点击“开始”。浏览器只会在首次点击后创建音频环境，这是浏览器自动播放规则的要求。
4. 点击 TAB 音符可改弦/品、插入、删除、锁定或重生成所在小节。

## 快捷键

`Space` 播放/暂停/继续；`Esc` 停止；`R` 回到开头；`←/→` 前后音；`↑/↓` BPM ±5；`F` 全屏；`L` 循环；`M` 节拍器。表单聚焦时快捷键不会触发。

## 音乐理论与路径逻辑

音高类别使用 0–11；实际音高使用 MIDI。1 弦始终位于最上方，数组也按 1 弦到 6 弦存储。每个和弦的音程与级数只定义在 `constants.js`。生成器先建立明确的六弦轨迹：上行走 6→1 弦、下行走 1→6 弦，往返在到达端点后沿相邻弦折返；额外节奏位置只分配给拥有多个可用和弦音的弦。随后动态规划从每根弦的和弦音中选择最低成本位置，用户音序作为优先级而不是破坏六弦轨迹的硬要求。相邻音不允许跳过中间弦，通常限制在 5 品移动内，必要时最多放宽至 7 品；同一根弦最多连续 3 音。上行和下行的 MIDI 方向是硬约束。和弦切换以小节线作为新六弦短句的起点，并优先选择近距离位置。

固定把位无法满足这些演奏约束时，程序会明确拒绝生成，并提供“放宽把位”“允许跨把位”“减少音序长度”三个可执行恢复操作，不再用生硬跨弦路径凑数。自动把位会搜索多个宽度和位置，选择移动量较低的有效路径。

为了同时保持六弦覆盖和节奏准确，纯上/下行每个和弦至少需要 6 个节奏位置，往返至少需要 7 个。设置不足时程序会要求提高音符细分或增加和弦拍数，而不会静默延长和弦。

## 浏览器兼容性

使用原生 HTML/CSS/ES6、Canvas、Web Audio、localStorage、Fullscreen 和 `<dialog>`。建议使用最新版 Chrome、Edge 或 Safari。文件下载、全屏和音频权限的提示样式由浏览器决定。

## 已知限制与合理方案

- CAGED 采用“依据根音定位的核心五品窗口”，严格模式不会绘制传统和弦图中的逐点形状边界；扩展模式在两侧各增加 2 品。
- 和弦进行当前共用每和弦拍数、把位与方向；通过“自动平滑连接”优化相邻和弦，但暂未提供每个和弦独立覆盖这些参数的表格编辑器。
- 左手指法是按把位映射的练习建议，不模拟横按、滑音或古典吉他全部指法。
- 合成音为轻量振荡器拨弦音色，不是录音采样；因此项目保持零外部资源、可离线运行。
- 预备拍按当前拍号播放一小节，并使用同一 Web Audio 时间轴调度；第一音在预备小节后精确进入。
- TAB 编辑支持逐音更改、插入、删除和锁定；“重生成本小节”会依据当前参数重建完整序列后定位回该小节。

## 测试

页面内置 `GAT_TESTS.run()`，覆盖文档中的 6 个和弦公式与 10 个标准调弦指板定位断言。路径批量回归覆盖全部根音、全部内置和弦、多种音序、方向、品位范围、4 种调弦和常用和弦进行；有效生成路径均检查相邻弦、品位跨度、MIDI 方向、连续同弦音数、重复音和范围越界。播放回归重点验证开始/暂停/继续/停止、循环、BPM 实时变化、快速操作去重、TAB/指板/信息同步、主题及本地保存。
