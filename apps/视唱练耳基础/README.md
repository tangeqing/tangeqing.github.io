# 听见 · 旋律听觉训练系统 V1.0

一个完全本地运行的吉他扒旋律专项训练网站。训练路径是：

`单音 → 音程 / 级数 → 短旋律 → 吉他指板 → 真实歌曲`

## 直接使用

双击 `index.html`，用现代版 Chrome、Edge、Firefox 或 Safari 打开即可。第一次播放声音时，浏览器会要求你主动点击播放按钮，这是 Web Audio API 的正常安全限制。

不需要安装 Node.js、Python、PHP，不需要启动本地服务器，也不需要联网。

## 功能范围

- 今日训练：按单音、构唱、音程、级数、短旋律、真歌依次训练。
- 单音训练：模唱、延迟记忆、音高匹配、音名识别、吉他定位。
- 音程训练：P1 至 P8 全部音程，自由组合，上行、下行、和声、听辨和构唱。
- 级数训练：自然大调 1 至 7，自由组合，听辨和构唱，支持 12 个调。
- 短旋律训练：轮廓、模唱、级数听写，3 至 8 音，五级难度，限制播放次数和记忆延迟。
- Melody Lab：导入本地歌曲、A/B 循环、70%—100% 速度、固定六步扒旋律流程、Heard / Tried 记录。
- 能力地图：十项能力评分、正确率、反应时间、Replay 次数和最近历史。
- 数据迁移：全部数据可导出为 JSON，并在另一浏览器中导入恢复。

## 本地数据与隐私

简单设置、训练记录、能力分数和自定义参数保存在浏览器 `localStorage` 中。为避免浏览器空间无限增长，最近训练明细最多保留 500 条；累计统计不会因此丢失。

导入的歌曲使用浏览器本地对象 URL 读取，只在当前页面存活，不会保存歌曲本体，也不会上传到任何服务器。关闭或刷新页面后需要重新选择歌曲。

## 文件结构

- `index.html`：应用入口和基础布局
- `styles.css`：响应式界面样式
- `js/music-theory.js`：音名、音程、调性、级数、指板与旋律语法
- `js/audio-engine.js`：Web Audio API 合成与播放
- `js/storage.js`：本地数据、统计、导入和导出
- `js/trainers.js`：四类人工生成训练逻辑
- `js/app.js`：页面、今日流程、Melody Lab 与能力地图

这些脚本采用普通 `defer` 脚本而非 ES Modules，以保证通过 `file://` 直接打开时核心功能也能运行。
