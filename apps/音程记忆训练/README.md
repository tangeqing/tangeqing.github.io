# 十二调音程与和弦组成音训练器

这是一个纯前端、离线可用的音乐理论反应训练工具。

## 运行

直接双击 `index.html`，用现代浏览器打开即可。无需安装、无需网络、无需后端。

答题默认使用按钮：单音、音程和和弦识别题点击后自动提交；多音与公式题按顺序点选后提交，并支持撤销、清空及数字键快捷选择。输入框作为备用方式保留。

## 数据

训练历史、熟练度、错题和设置均保存在当前浏览器的 `localStorage`。可在“学习统计”页导出或导入 JSON 备份。

## 文件

- `musicTheory.js`：音程字母级数 + 半音距离计算、和弦公式数据库
- `storage.js`：本地数据、错题与熟练度算法
- `app.js`：训练流程、智能权重、统计、音频与快捷键
- `styles.css`：响应式界面与深浅色主题
